# Input Data Attribution

This folder contains publicly available datasets from the  
National Administrative Department of Statistics of Colombia (DANE): https://www.dane.gov.co/

**Note:** These datasets are re-hosted here for academic reproducibility purposes only.  
For the most current data, please refer to the original DANE portal.

## Source
Departamento Administrativo Nacional de Estadística – DANE, Colombia.  
Original datasets can be accessed directly from: https://www.dane.gov.co/
