KEY DESIGN CHOICES
================================================================================

1. SAME GRID FOR ALL THREE LAYERS (malls, hospitals, schools)
   → Ensures direct comparability
   → Uses cached grid from walking_time_mall.parquet
   
2. LOCAL DIJKSTRA ROUTING (not Valhalla API)
   → Reproducible (no API dependencies)
   → Deterministic (no network variability)
   → Fast (~20 sec vs. ~10 min)
   → Validated: 94.7% agreement with Valhalla on malls test
   
3. WALKING SPEED: 4.7 km/h
   → Calibrated against Valhalla pedestrian costing
   → Fixed constant (no slope adjustment, but documented as limitation)
